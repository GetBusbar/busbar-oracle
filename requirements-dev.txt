# The oracle's development dependencies, pinned by version AND by digest.

# The oracle decides whether somebody shipped a regression, so its own CI is the boring kind: a
# linter that could change between two runs is one more way a verdict about a product could be a

# install anything whose bytes are not named here, and refuses the whole file if any requirement
# lacks a hash -- so a dependency added without one fails loudly rather than floating.
#

# pip picks the file matching the platform it is running on, and CI (ubuntu x86_64), a maintainer on
# an arm64 Mac and a contributor on Windows must all be held to the same pin. The sdist is here for
# a platform with no wheel.
#

#

# recorder can only run mutation cells on a host with PyYAML (record.sh says so out loud -- a
# missing PyYAML is exit 2, "the tool failed", never a named gap). But this package must be
# installable into a venv that shares nothing with the workspace it judges, so `dependencies` in
# pyproject.toml stays empty and PyYAML stays a thing the PRODUCT's environment provides.
#

# pytest, for tests/ (0.3.12). The tool's own drivers each carry a `--selftest` and CI runs them,
# and those stay: they are what a maintainer runs on a machine with nothing installed, and what the
# fixture-product job proves the shipped package with. pytest is added BESIDE them, for the thing a
# `--selftest` cannot do well -- one named, independently-reported assertion per behaviour, so a
# regression says which of forty behaviours broke instead of "RED (1 failing)".
#
# STILL NO RUNTIME DEPENDENCY, AND STILL NO `websockets`. The obvious way to test a WebSocket
# recorder is to drive it from a WebSocket library, and it is the wrong way here twice over: it
# would be a second, differently-opinionated implementation of the thing under test (a library that
# coalesces fragments or answers pings on your behalf cannot be used to prove that this recorder
# does not), and it would put a package between the oracle and the workspace it must share nothing
# with. tests/ drives the drivers with a scripted server built out of wsframe itself and stdlib
# sockets, on an EPHEMERAL port, and pyproject's `dependencies = []` is untouched.
#
